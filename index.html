Зерттеу шығармалары

«Көшпенділер»

І. Есенберлин. Қазақ хандығы дәуірінің тарихи-көркем бейнесі.

Абылай хан

З.С. Тайшыбай жинағындағы құжаттар мен «Көшпенділердегі» көркем бейне салыстырылады.

«Тар жол, тайғақ кешу»

С. Сейфуллин. ХХ ғасыр басындағы саяси оқиғалардың авторлық-мемуарлық көрінісі.

🖼 Тарихи тұлғалар мен оқиғалар галереясы

Бұл бөлім тарихи тұлғаның/оқиғаның көрнекі бейнесін тарихи ақпаратпен бірге қарастыруға арналған. Әр суреттің астында дереккөзі көрсетілді.

Абылай хан

Тарихи тұлға. XVIII ғасырдағы қазақ ханы, әскери және саяси қайраткер. Жобада оның тарихи құжаттардағы мәліметтері І. Есенберлиннің «Көшпенділеріндегі» көркем бейнемен салыстырылады.

Сурет: «Жауһар» галереясы. Сурет көркем портрет ретінде берілген; оны замандас фотосурет деп қабылдауға болмайды.

Сәкен Сейфуллин

Әдебиет және тарих. «Тар жол, тайғақ кешу» шығармасында 1916–1919 жылдардағы оқиғаларды, өзінің көрген-білгендерін және саяси өзгерістерді баяндайды.

Сурет: Zharar.com материалындағы портрет.

Қазақ хандығының құрылуы

Тарихи оқиға. Керей мен Жәнібек сұлтандардың көшуі және Қазақ хандығының қалыптасуы 1465–1466 жылдармен байланыстырылады.

Карта: ашық интернеттегі оқу материалы. Зерттеу үшін деректі E-history.kz хронологиясымен тексеру ұсынылады.

1916 жылғы ұлт-азаттық қозғалыс

Тарихи оқиға. Бірінші дүниежүзілік соғыс жағдайындағы патша жарлығы мен отарлық саясатқа қарсылық Қазақстандағы 1916 жылғы көтерілістің маңызды алғышарттарының бірі болды.

Ақпарат: E-history.kz. Сурет жүктелмесе, оқиға карточкасы мәтіндік режимде қалады.

📝 Оқушының онлайн тесті

Алдымен аты-жөніңіз бен сыныбыңызды енгізіңіз. Тест аяқталған соң нәтиже экранда көрсетіледі. Мұғалімге жіберу үшін төмендегі Google Apps Script нұсқаулығын орындап, сайттың баптау бөліміне Web App URL енгізіледі.

Нәтиже әлі есептелген жоқ.

Ескерту: Web App URL енгізілмесе, «Мұғалімге жіберу» батырмасы тек жергілікті режимде нәтиже көрсетеді.

Сұрағыңызды енгізіңіз.

📊 Нәтиже

Тестті тапсырғаннан кейін жеке нәтижеңіз осында көрсетіледі.

👩‍🏫 Мұғалімге арналған онлайн нәтиже жүйесі

Оқушылардың жауаптарын интернет арқылы жинау үшін Google Sheets + Google Apps Script қолдануға болады. Бұл тәсілде нәтижелер кестеге автоматты түседі.

  1. Google Sheets-та жаңа кесте ашыңыз.
  2. Extensions → Apps Script бөліміне кіріңіз.
  3. Төмендегі дайын Apps Script кодын орналастырыңыз.
  4. Deploy → New deployment → Web app → Anyone етіп жариялаңыз.
  5. Шыққан Web App URL-ін осы сайттың WEB_APP_URL айнымалысына енгізіңіз.

Маңызды: Web App URL-ін сайттың кодына енгізбей тұрып оқушылардың нәтижесі ортақ кестеге түспейді.
